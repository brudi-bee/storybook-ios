# Stories-Verzeichnis

Hier werden wöchentlich neue Märchen gespeichert.

## Format
- `WEEK-XX.json` - Jeweils 3 Geschichten pro Woche
- Struktur: Siehe docs/BACKEND_API_SPEC.md

## Wie es funktioniert
- Jeden Montag 9 Uhr: Automatische Generierung
- Brudi (kimi-k2.5:cloud) erstellt die Stories
- Die App lädt die neueste Woche beim Start

## Manuelle Stories
Du kannst auch eigene Stories als JSON hinzufügen.
