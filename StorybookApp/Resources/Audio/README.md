# Audio Assets für Storybook App

## Ordner-Struktur

```
Audio/
├── calm/
│   ├── bgm_calm_01.mp3      # Sanfte Klaviermusik
│   ├── bgm_calm_02.mp3      # Leichte Naturgeräusche
│   └── bgm_calm_03.mp3      # Beruhigende Melodien
├── happy/
│   ├── bgm_happy_01.mp3     # Fröhliche Melodien
│   └── bgm_happy_02.mp3     # Spielerische Töne
├── peaceful/
│   ├── bgm_peaceful_01.mp3  # Entspannende Musik
│   └── bgm_peaceful_02.mp3  # Meditation/Traumhaft
├── tense/
│   └── bgm_tense_01.mp3     # Spannende Momente
└── sound_effects/
    ├── page_turn.mp3        # Seite umblättern
    ├── success.mp3          # Erfolgs-Sound
    └── magic.mp3            # Magischer Moment
```

## Anforderungen

- **Format:** MP3 oder M4A (AAC)
- **Bitrate:** 128-192 kbps
- **Länge:** 30-60 Sekunden (loopbar)
- **Lautstärke:** Normalisiert auf -14 LUFS
